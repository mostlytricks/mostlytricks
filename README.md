## 🪐 What I actually build

Most of my work lives one layer beneath the app: the **infrastructure that makes AI agents dependable**. Specs they can't drift from, skill registries they pull from, orchestration surfaces humans can supervise, and a documentation system that keeps a dozen projects from collapsing under their own entropy.

I have a mild habit of naming things after celestial objects — partly because it maps cleanly onto "a system and the fleet that orbits it," and partly because `utils-final-FINAL-v2` never sparked joy. 🌌

## 🛰️ The Fleet

| Project | What it is |
| :--- | :--- |
| **[gravity](https://github.com/mostlytricks/ai-workspace)** | A documentation-as-OS for AI coding agents — versioned conventions, faceted specs, and slash commands that keep long-lived projects coherent. The star everything else orbits. |
| **[sol](https://github.com/mostlytricks/sol)** | A desktop mission-control surface (Electron + React) for supervising local coding agents — board, adapters, MCP/skills/memory panels. |
| **[nova](https://github.com/mostlytricks/nova)** | An intranet `llms.txt` control plane — a namespaced, verified doc source so offline agents read from ground truth, not guesses. |
| **[orbit](https://github.com/mostlytricks/orbit)** ↔ **[astra](https://github.com/mostlytricks/astra)** | A skill workbench (`orbit`) that designs agent skills at home, and an immutable skill registry (`astra`) that ships them to locked-down work machines. |
| **[forge-world](https://github.com/mostlytricks/forge-world)** | A game-feel semiconductor stack-up simulator (Three.js) — because sometimes you want to teach etch-and-deposit by *playing* with it. |

<sub>…plus a longer tail of MCP servers, spec-driven pipelines, and knowledge tools. I don't run out of ideas; I run out of coffee.</sub>

## 🪐 실제로 만드는 것

제 작업 대부분은 앱보다 한 층 아래에 있습니다. 바로 **AI 에이전트를 믿을 수 있게 만드는 인프라**입니다. 벗어날 수 없는 스펙, 끌어다 쓰는 스킬 레지스트리, 사람이 감독할 수 있는 오케스트레이션 화면, 그리고 수십 개 프로젝트가 자기 엔트로피에 무너지지 않게 잡아 주는 문서 시스템.

프로젝트 이름을 천체에서 따오는 버릇이 있습니다 — "하나의 시스템과 그 주위를 도는 함대"라는 구조에 딱 맞기도 하고, `utils-final-FINAL-v2` 같은 이름은 도무지 정이 안 가서요. 🌌

## 🛰️ 함대 (The Fleet)

| 프로젝트 | 무엇인가 |
| :--- | :--- |
| **[gravity](https://github.com/mostlytricks/ai-workspace)** | AI 코딩 에이전트를 위한 *문서-운영체제*. 버전 관리되는 규약, 도메인별 스펙, 장수 프로젝트를 일관되게 유지하는 슬래시 커맨드. 나머지 모두가 공전하는 별. |
| **[sol](https://github.com/mostlytricks/sol)** | 로컬 코딩 에이전트를 감독하는 데스크톱 관제 화면 (Electron + React) — 보드, 어댑터, MCP/스킬/메모리 패널. |
| **[nova](https://github.com/mostlytricks/nova)** | 사내망 `llms.txt` 컨트롤 플레인 — 오프라인 에이전트가 추측이 아닌 검증된 원본 문서를 읽도록 하는 네임스페이스 문서 소스. |
| **[orbit](https://github.com/mostlytricks/orbit)** ↔ **[astra](https://github.com/mostlytricks/astra)** | 집에서 에이전트 스킬을 설계하는 워크벤치(`orbit`)와, 그 스킬을 폐쇄망 업무 PC로 배포하는 불변 레지스트리(`astra`). |
| **[forge-world](https://github.com/mostlytricks/forge-world)** | 게임 감성의 반도체 적층 시뮬레이터 (Three.js) — 식각·증착을 *가지고 놀며* 가르치고 싶을 때. |

<sub>…그 외에도 MCP 서버, 스펙 기반 파이프라인, 지식 도구들이 줄줄이. 아이디어는 안 떨어지는데, 커피가 떨어집니다.</sub>
